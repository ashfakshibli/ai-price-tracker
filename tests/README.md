# Tests

This directory contains test files for the AI Price Tracker.

## Test Files

- `test_check_single.py` - Test single product checking
- `test_frequency_selector.py` - Test cron frequency selection
- `test_initial_check.py` - Test initial product check
- `test_product_ids.py` - Test product ID handling
- `test_product_name_edit.py` - Test product name editing
- `test_product_sorting.py` - Test product sorting
- `test_variant_detection.py` - Test variant detection
- `test_inline_edit.html` - Test inline editing UI

## Running Tests

```bash
# Run specific test
python tests/test_check_single.py

# Or run from project root
python -m pytest tests/
```
